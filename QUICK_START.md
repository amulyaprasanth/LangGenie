# 🚀 LangGenie Quick Start Guide

## ⚡ Super Fast Setup

### Windows Users
1. Double-click `install.bat`
2. Wait for installation to complete
3. Browser opens automatically to http://localhost:3000
4. Start using LangGenie! 🎉

### Linux/macOS Users
```bash
chmod +x install.sh
./install.sh
```

## 📝 Using LangGenie

### Step 1: Upload PDF
- Go to http://localhost:3000
- Click "DocQnA & Content Generator"
- Upload your PDF file

### Step 2: Choose Mode
- **Q&A** 💬 - Ask questions about the document
- **Speech** 🎤 - Generate speeches from content  
- **Article** 📰 - Create comprehensive articles
- **Blog** ✍️ - Write engaging blog posts

### Step 3: Generate Content
- Type your request
- Click Send or press Enter
- Watch AI create amazing content!

## 🔧 Basic Commands

```bash
# Start LangGenie
docker-compose up -d

# Stop LangGenie
docker-compose down

# View logs
docker-compose logs -f

# Check status
docker-compose ps
```

## 🌐 Access Points

- **App**: http://localhost:3000
- **API**: http://localhost:8000
- **Ollama**: http://localhost:11434

## ❓ Need Help?

1. Check the main [README.md](README.md) for detailed instructions
2. Look at the troubleshooting section
3. Make sure Docker is running
4. Ensure ports 3000, 8000, 11434 are available
